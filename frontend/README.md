# Prompt Heist frontend

One Flutter web app with three routes (decision D9):

| Route | Surface | Code |
|---|---|---|
| `/player` (also the bare domain) | Player phones | `lib/features/player/` |
| `/controller` | Booth Controller dashboard | `lib/features/controller/` (deferred import) |
| `/audience` | Public big screen ("display" in the API) | `lib/features/audience/` (deferred import) |

The Controller and audience code is loaded with deferred imports, so phones only download the player code (FE-01). Release builds use `--no-web-resources-cdn`, so the rendering engine (CanvasKit) comes from our own site, not a Google CDN. Deferred imports mean Flutter cannot content-hash file names, so Hosting must revalidate the JS files on every load (FE-04).

Fonts are bundled in `assets/fonts/`: Inter (`AppSans`), JetBrains Mono (`AppMono`) and Noto Color Emoji (`AppEmoji`, the emoji fallback, subset to faces and common reactions), so nothing is fetched from Google Fonts at runtime. Google Sans and Google Sans Code (SIL OFL, subset to Latin) are the app's Google theme (FE-26): `buildHeistTheme()` and `HeistThemeScope`, set once in `app.dart` for every route. The audience big screen draws its own fixed stage. The widget gallery for design review is at `/gallery`.

Flutter stable · Riverpod · go_router (path URLs) · Dio + Retrofit client generated by swagger_parser · socket_io_client

## Commands

```sh
flutter pub get
flutter run -d chrome --web-port 5000                                              # real API on :4010, e.g. the BE-02 replay server
flutter run -d chrome --web-port 5000 --dart-define-from-file=config/mock.json    # in-app mock, no server needed
flutter run -d chrome --web-port 5000 --dart-define-from-file=config/local.json   # against a local backend
flutter analyze
flutter test --dart-define-from-file=config/mock.json   # the tests run against the in-app mock
flutter build web --release --no-web-resources-cdn --dart-define-from-file=config/<flavour>.json
```

Regenerate the API client after `contract/openapi/openapi.yaml` changes:

```sh
dart run swagger_parser
dart run build_runner build
```

## Layout

| Path | Purpose | Stories |
|---|---|---|
| `lib/main.dart` | Entry: path URL strategy, `ProviderScope` | FE-01 |
| `lib/app/` | App widget, router, build-time `Env`, deferred loading helper | FE-01 |
| `lib/core/api/` | Generated client (`generated/`), token interceptor, typed errors | FE-02 |
| `lib/core/realtime/` | Socket client with auto-reconnect and rehydrate | FE-02 |
| `lib/core/mock/` | In-app mock used by the `mock` flavour. `mock_world.dart` drives the player flow; `mock_display.dart` loops a scripted show on `/audience` (jump ahead with `?start=JOINING`, `TREASURE_REVIEW`, `PLAYING` or `RESULT_PENDING`; press O to drop the connection for 10 seconds; add `&discard` to see a discarded round). `mock_controller.dart` is the booth behind `/controller`: sign in as `controller` / `devfest`; its state lives in sessionStorage so refresh checks work. Tests force each error path through `MockController.setDemo` | FE-02, FE-11–23, FE-27, FE-28 |
| `lib/core/storage/` | Player token saved in the browser, so a phone can rejoin | FE-06, FE-07 |
| `lib/core/wake/` | Screen wake lock for the audience display | FE-19 |
| `lib/core/timer/` | Server-synced countdown | FE-03 |
| `lib/core/theme/` | Google logo palette, score colours (`score_colors.dart`) | FE-26 |
| `lib/core/widgets/` | Shared widgets (`TimerPill`, `TreasureImage`, `ShapeMarker`, …) and gallery | FE-26 |
| `lib/features/player/` | Join, lobby, rejoin, battle, feedback, result | FE-05–10 |
| `lib/features/controller/` | Login, setup, treasure review, ready, name review, monitor, result, event day, audit | FE-11–18, 27, 28 |
| `lib/features/audience/` | Idle, joining, battle, unlock, results | FE-19–23 |
| `assets/fonts/` | Bundled fonts. Never fetched at runtime, because booth Wi-Fi can't be trusted | FE-01, FE-26 |
| `config/` | Flavour files for `--dart-define-from-file`. A production flavour is added with FE-04 | FE-01 |
| `test/app/` | Router tests. One deferred route per test file (see `test_app.dart` for why) | FE-01 |
| `test/` | Unit and widget tests for the API errors, countdown, booth code, lobby and rejoin routing | FE-02–07 |
